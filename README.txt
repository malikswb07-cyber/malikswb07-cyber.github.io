SOUMEN MALIK — PORTFOLIO WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the website.
3. For editing, open the whole malik_portfolio folder in VS Code.
4. Replace YOUR_EMAIL_ADDRESS_HERE in js/script.js with your real email address.
5. The supplied profile photo is in assets/profile.jpg.
6. cv.pdf is a starter CV. Check it carefully and add verified phone/email, marks, projects, certificates, and dates before using it professionally.
7. Light/dark mode remembers the visitor's choice. Navigation adapts to mobile screens.

DEPLOYMENT
You can upload the folder to a static host such as GitHub Pages or Netlify. Keep the folder structure intact.
